# Как получить APK через GitHub Actions

## Что это такое
GitHub — бесплатный сервис. Ты загружаешь туда код,
их серверы сами собирают APK и ты скачиваешь готовый файл.
Регистрация бесплатная, кредитная карта не нужна.

---

## Шаг 1 — Создай аккаунт на GitHub

1. Открой https://github.com
2. Нажми **Sign up**
3. Введи email, придумай пароль и username (латинскими буквами)
4. Подтверди email

---

## Шаг 2 — Создай репозиторий

1. После входа нажми кнопку **+** (вверху справа) → **New repository**
2. Repository name: `vpnapp`
3. Выбери **Private** (чтобы только ты видел)
4. Нажми **Create repository**

---

## Шаг 3 — Загрузи файлы

На странице нового репозитория нажми **uploading an existing file**

Загрузи ВСЕ файлы и папки из архива `vpnapp_clash.zip`.

> **Важно:** нужно загрузить именно содержимое папки `vpnapp2`,
> а не саму папку. То есть файлы `build.gradle`, `settings.gradle`,
> папки `app/`, `.github/` и т.д. должны быть в корне репозитория.

Проще всего сделать так:
1. Распакуй архив
2. Открой папку `vpnapp2`
3. Выдели ВСЕ файлы внутри (Ctrl+A)
4. Перетащи их на страницу GitHub в браузере

Нажми **Commit changes**.

---

## Шаг 4 — Запусти сборку

1. На странице репозитория нажми вкладку **Actions**
2. Слева увидишь **Build APK**
3. Нажми на него → нажми кнопку **Run workflow** → **Run workflow**
4. Подожди 3–5 минут (будет крутиться жёлтый кружок)

---

## Шаг 5 — Скачай APK

1. Когда кружок станет зелёной галочкой — сборка готова
2. Нажми на строку **Build APK**
3. Внизу страницы найди раздел **Artifacts**
4. Нажми **VPNApp** — скачается ZIP
5. Распакуй ZIP — внутри файл `app-debug.apk`

---

## Готово!

Перенеси APK на телефон и установи
(см. шаги 6–8 из основной инструкции).
